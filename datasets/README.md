# Datasets

Shared or reusable datasets for the projects in this repo go here — e.g. a
common product/store master list used by multiple projects.

Per-project synthetic datasets that only that project needs (like
`01-sales-dashboard`'s transaction log) live inside the project's own folder
instead, to keep each project self-contained.

## Sources for real practice data

- Kaggle: "Retail Sales", "Superstore Sales", "Online Retail" datasets
- Synthetic data generated on request (see each project's README for its
  generation approach)
